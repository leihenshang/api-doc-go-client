# 客户端与服务端同步 · 实现全景

> 2026-10-16 由《客户端与服务端同步实现现状》与《同步字段补全与响应类型改造方案》两文合并，全部内容依三仓当前代码实读核对（api-doc-go-client / api-doc-go / api-doc-go-share），不含历史规划叙述。

## 一、功能模块与完成情况（总览）

| # | 功能模块 | 完成情况 | 关键说明 |
|---|---|:--:|---|
| 1 | 真相源模型 | ✅ | 客户端：集合为纯文本 YAML（Bruno 风格），文件即真相源、离线可用；服务端：SQLite/PostgreSQL 项目数据 + 只存"指针"的 `change_log` 流水表（项目级游标=自增 id） |
| 2 | 绑定与模式 | ✅ | 绑定是**每个集合的属性**，存集合目录 `.sync.json`（0600，已进集合自动维护的 `.gitignore`：不进版本库、不随集合共享）；含 PAT（重启免重填，解析顺序：显式参数→会话内存→`.sync.json`）；`auto`（定时双向，默认 120s、仅活动集合）/ `manual` / `mirror`（只拉）/ 未关联=纯单机；非回环地址禁明文 http（`ValidateServerURL`）；分享已绑定集合需先解绑 |
| 3 | 单轮流程（先 pull 后 push） | ✅ | `state` 探游标 → `changes` 增量（每页 500、单轮 ≤200 页、游标不前进即停）→ `gap`/首次走 `snapshot` 全量；应用按拓扑序：group → doc/api → example → variable_env → variable；push 提交精确 dirty + tombstone |
| 4 | 冲突处理 | ✅ | push 的 `base_rev` ≠ 服务端 `last_change_id` → `conflict` 并附服务端版本；服务端版本落回原文件、本地版本另存 `.conflicts/*.yml`（该条仍 dirty），UI「以本地/以远端/保留副本」三选一；pull 覆盖本地未推改动前先 `saveLocalIfDirty`。字段级三方合并不做（既定） |
| 5 | 服务端机制 | ✅ | 实体均带 `ext_uid`（客户端 UUID，离线改名不丢身份）+ `last_change_id`；Web 写操作同记流水（device=`"web"`）；`sync_op` 按 `op_id` 幂等；`AuthOrPAT` 双鉴权（PAT 侧还原真实用户类型并校验用户状态）；`client_write_enabled=false` → `rejected.readonly`。**权限位矩阵**：`SyncState/Changes/Snapshot` 须 `PermQuery`；`SyncPush` 写须 `PermUpdate`、批内含删除再须 `PermDelete`；代码导出/变量明文回显（`resolve=1`/`with_value`）另须 `canRevealValues`（管理员/负责人/update）（单测 `TestSyncPushRequiresProjectPermission`） |
| 6 | 同步实体类型 | ✅ | 六类：`group / api / doc / example / variable_env / variable`（`model/sync.go` 常量 + `change_log` + 冲突检测/快照/删除全管线）；`field_mapping` 未进同步（服务端独有、客户端无模型，见 §四） |
| 7 | 接口携带字段（21 个） | ✅ | 全部端到端：客户端 `SyncExtra` 整份下发 → 服务端文本列原样存储（不解释语义）→ `apiSyncPayload` 同键集回传（增量/快照共用）→ Web 只读展示。映射明细见 §二 |
| 8 | 响应类型与多示例 | ✅ | `ResponseDoc.ContentType`（json/text/xml/html/binary）落盘走 respDoc JSON、随 `retContentType` 同步；多响应示例为独立实体 `example`（服务端表 `api_return_sample`：`name/status/content_type/seq/api_uid`），客户端可命名保存、Web 示例选择器切换查看 |
| 9 | secret 变量加密链路 | ✅ | secret 变量值**客户端口令（passphrase）scrypt→AES-256-GCM 加密**（`internal/secrets`，密文 `enc:v1:` 前缀）后出网；**服务端只存密文、不解析**：`resolveTable` 跳过 `enc:v1:`（占位符原样保留，Mock/cURL/代码生成均不消费）；未设口令时 secret 不同步（明文不出本机）；口令存配置目录 0600（`sync_passphrase`），Web 变量按 `is_secret` 掩码 |
| 10 | 客户端录入 UI | ✅ | 请求体「原文/表格」切换 + 字段备注编辑（`BodyFieldsTable.vue`→`body.descs`，e2e `[B5]` 验证落盘）；Resp 段类型下拉+徽标、响应快照按类型渲染（`resp.contentType*`）；同步弹窗口令设置区（`sync.pass*`，UI 只显示「是否已设置」、永不回显口令） |
| 11 | Web 端展示 | ✅ | 接口详情新增「请求体/认证/请求设置/脚本」四段（查看态、有内容才显示、进大纲 scroll-spy）+ 返回参数内容类型徽标；认证密码/令牌掩码、设置三态（开/关/未设置）、请求体含 form 行表与 bodyDescs 备注表；Web 保存以 `...ext` 原样回传，防整条覆盖误清同步值 |
| 12 | 脏检测（推送效率） | ✅ | 接口/分组走索引 `DirtyNodes()` 文件 hash；doc 走 `Bind.DocHashes`、example 走 `ExampleHashes`、环境/变量走 `EnvHashes/VarHashes`（sha-256 内容摘要，uid 缺失推送时自动补齐落盘），均「只推变化项 + 消失即 tombstone」，回执成功后固化 |
| 13 | 多客户端协作场景 | ✅ | 共享一条 change_log 各维护 cursor；`actor/device` 溯源；同名新建不猜不合并；删除经 tombstone 不复活；长期离线 gap→snapshot 自动对齐；只读成员 push 得 `rejected.forbidden` 属正常路径 |

## 二、字段映射与展示位置（与代码逐字对齐）

### 2.1 接口（api）携带的 21 个字段

同步键契约：客户端 `internal/collection/sync_extra_fields.go` / `syncrows.go` ↔ 服务端 `applyApiExtra`/`apiSyncPayload` ↔ Web `ApiDetailView.vue` 解析键，三方逐字一致。存储与回传统一语义：**整份覆盖、空串清空、缺键不动**（新旧两端互相兼容）。

| # | 字段（extra 键） | 内容 | 服务端列（api 表） | Web 展示位置 |
|---|---|---|---|---|
| 1 | name | 接口名 | `api_name` | 标题栏 |
| 2 | method | 方法 | `http_method_type` | URL 栏方法徽标 |
| 3 | url | 地址 | `url` | URL 栏 |
| 4 | group_uid | 所属分组 | `group_id` | 左树 + 编辑态分组下拉 |
| 5 | protocol | 请求协议 | `protocol_type` | 查看态小徽标 |
| 6 | headers | 请求头行 JSON | `http_request_header` | 「请求头部」段（`data-sec=headers`） |
| 7 | params | 请求参数行 JSON | `http_request_params` | 「请求参数」段（`data-sec=params`） |
| 8 | retType | 返回根类型 | `http_return_type` | 「返回参数」标题旁徽标 |
| 9 | retParams | 返回参数行 JSON | `http_return_params` | 「返回参数」段（`data-sec=result`） |
| 10 | retSample | 响应样例（主） | `http_return_sample` | 「响应样例」段（`data-sec=sample`） |
| 11 | desc | 接口说明（Markdown） | `description` | 「文档」段（`data-sec=doc`） |
| 12 | bodyType | none/json/text/form/multipart | `http_request_body_type` | 「请求体」段标题旁类型标签 |
| 13 | body | json/text 原文 | `http_request_body` | 「请求体」段代码块（`data-sec=body`） |
| 14 | bodyForm | form/multipart 行 JSON | `http_request_body_form` | 「请求体」段行表（名/值/备注） |
| 15 | bodyDescs | JSON 体字段备注 `path→备注` | `http_request_body_descs` | 「请求体」段 path→备注表（客户端表格视图录入） |
| 16 | auth | `{type,username,password,token,key,value,in}` JSON | `http_auth` | 「认证」段（`data-sec=auth`，密码/令牌掩码） |
| 17 | settings | 请求设置 JSON（三态在 JSON 内编码 `-1/0/1`，`encodeUrl` 为 `*bool`） | `request_settings` | 「请求设置」段（`data-sec=settings`，开/关/未设置） |
| 18 | script | `{preRequest,postResponse}` JSON | `http_script` | 「脚本」段代码块（`data-sec=script`） |
| 19 | vars | 前置变量行 JSON | `script_vars` | 「脚本」段变量表 |
| 20 | asserts | 断言行 JSON | `script_asserts` | 「脚本」段断言表 |
| 21 | retContentType | 响应内容类型 | `http_return_content_type` | 「返回参数」徽标（与根类型并列） |

- 12–21 为富字段：服务端按**不透明 JSON/文本列**存储（迁移 sqlite `0013_api_client_fields` / postgres `0012_api_client_fields`；dev 由 GORM AutoMigrate 自动建列），不做字段级查询/校验。
- `encodeUrl` 三态源于共享包 `RequestSettings.EncodeURL *bool`（v0.8.0）；`runner.buildURL` 已消费（默认编码，`false` 原样拼接），未配置行为与历史逐字节一致。

### 2.2 实体载荷（同步 payload 键 ↔ 服务端表）

| 实体 | 载荷键 | 服务端表/列 | 备注 |
|---|---|---|---|
| group | title / parent_uid / priority | `group`（ext_uid/last_change_id） | 删除只软删组本身，子项呈"未分组" |
| doc | title / content / icon | `doc`（ext_uid/last_change_id） | 脏检测走 `DocHashes` |
| example | name / api_uid / sample / status / content_type / seq | `api_return_sample` | 依赖请求文件，排序在其后 |
| variable_env | name | `variable_env`（+ ext_uid/last_change_id，迁移 sqlite `0014` / postgres `0013`） | 名称变化=客户端 `RenameEnv` |
| variable | name / value / secret / enabled(*bool) / env_uid | `variable`（scope=项目级，同上迁移） | value 或明文或 `enc:v1:` 密文，服务端原样存 |

## 三、核心代码地图

- 客户端：`internal/syncengine/{engine,client}.go`（引擎/载荷/`BindInfo` 各 Hashes）、`internal/collection/{syncrows,sync_extra_fields}.go`（extra 契约）、`internal/secrets/secrets.go`（口令加密）、`frontend/src/{lib/bodyFields.ts,components/BodyFieldsTable.vue,RequestEditor.vue,SyncDialog.vue}`
- 服务端：`server/internal/service/sync.go`（`applyApiExtra`/`apiSyncPayload`/`applyUpsert`/快照/权限位）、`server/internal/{model/api,model/variable,model/sync}.go`、`server/migrations/{sqlite,postgres}/0012–0014`
- Web：`web/src/views/project/ApiDetailView.vue`（`ext` 状态 + 四段 + `resultTitleExtra`）、`web/src/types/entities.ts`
