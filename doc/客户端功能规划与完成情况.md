| 端到端 | `go build -o .tmp/devserver-test ./cmd/devserver` → 以**独立端口/独立 `XDG_CONFIG_HOME`** 启动 → 浏览器驱动 | 打开集合 → 打开请求 → 严格模式发自签 HTTPS 失败 → 设置开启忽略 SSL → 200 → 认证头真实注入 → 历史记录 |

**回归要点（改动执行器/文件层时必跑）**：
1. 证书策略：严格必须失败、忽略必须成功（自签端点 `-tls-echo`）。
2. 重定向：跟随/不跟随/超上限三种行为。
3. round-trip：Bruno 样例句含 `auth: inherit`、`vars/script/assert` 时，读入保存后**未知字段不丢**。
4. 自写回环：自动保存不应把编辑器内容覆盖掉（批次 2 引入 fsnotify 后强制回归）。
5. 树操作：空分组可见、重命名后目录名/uid 不变、非空分组拒绝删除、删除进 `.trash`（`internal/collection/folder_test.go`）。
6. 界面：语言切换即时生效、界面缩放 200% 无溢出、响应区右侧/底部切换（浏览器手动验证）。
7. Markdown：预览渲染 h2/表格/列表，且原始 HTML（`<script>`/`onerror`）必须被转义（md-editor-v3 默认转义，已验证）。
8. 详情页布局：请求栏宽度 = 详情区宽度；「响应区位置」右侧/底部两种布局下均无溢出。
9. 与设计稿一致性（design-spec §1）：`body` 字号 13px；naive-ui 组件圆角 6px；`--app-bg=#f5f5f5`、`--app-border=#e3e3e3`、`--app-text=#202124`（改动主题或基础样式时用 `getComputedStyle` 复核）。
10. 字体：`document.fonts.check('13px "Noto Sans SC Variable"', '用户管理')` 必须为 `true`；`body` 的 `font-synthesis` 为 `none`（避免中文合成粗体）；拉丁字宽应与系统字体不同（证明内置字体生效）；构建后 `dist/assets/*.woff2` 存在。
11. tab↔树联动：打开请求后侧栏对应行有 `.on`；切换 tab 后选中态随之移动；祖先分组被收起时切到该 tab 会自动展开并滚动到可见；`document.title` 为 `api-doc-go`。
12. 弹窗不挤布局：在 uiScale=1 与 1.5 下分别记录「无弹窗 / 全局设置 / 请求历史 / 新建请求 / 关闭后」五种状态的 `.app`、`.work`、请求区、响应区尺寸，必须完全一致且无横向溢出。
13. 分栏拖动：右侧布局横向拖动、底部布局纵向拖动后，响应区占比等于拖动位置（±1%）；刷新后沿用；分隔区固定 28px，中央胶囊两个按钮可切换 right/bottom（激活按钮主色），在胶囊上按下不应触发拖动。
14. 外壳：标题栏/工具栏/状态栏常驻（未打开集合时也渲染标题栏，保证无边框窗口始终有拖动区）；状态栏的请求数/环境数与集合树一致；未选中请求时主区展示 `Collection` 概览页（概况 + 六大特性卡）。
15. 命令面板：Ctrl+K 唤起、ESC 关闭；chips 过滤生效；上下键移动选中行并滚动到可见；回车分别执行打开请求 / 切换环境 / 运行命令；面板打开期间输入不落到编辑器。
16. 请求面板与地址栏：参数表「说明」列保存后重开仍在（`KV.Description` round-trip）；Bulk Edit 切多行后同名行的启用态与说明保留；URL 中 `{{变量}}` 显示主色底纹；方法选择器底色随方法变化。

## 6. 已知差异与风险

| # | 事项 | 影响 | 处理建议 |
|---|---|---|---|
| 1 | 自动保存防抖 **800ms** vs 设计文档 500ms | 少量不一致 | 确认取哪个值，统一后写回设计文档 |
| 2 | i18n 仅 105 key（服务端 407） | 文案不齐但不阻塞 | 随功能补齐，不必强搬整包 |
| 3 | 无 fsnotify（D1/D2） | 外部改动/`git pull` 后需手动重扫 | 批次 2 引入，并做自写回环抑制 |
| 4 | 无 SQLite 索引（C1） | 大集合扫描性能未验证 | 批次 2；先补基准用例再决定 |
| 5 | `settings.encodeUrl` 仅保留不生效 | 与 Bruno 行为差异（不编码 `{}` 等） | 视需要实现或明确文档标注 |
| 6 | 二进制响应无保存入口（E21） | 大响应只能在 UI 看 base64 | 批次 2 |
| 7 | 请求级 `settings` 无 UI | 只能手改 YAML | 可在编辑器加「请求设置」折叠区 |
| 8 | 无取消发送（G5） | 长超时请求只能等 | 批次 1（context 透传） |
| 9 | secret 明文落 `*.secrets.yml` | 已 gitignore，但本机明文 | 设计文档 Q2 已定：E2EE 后续（不改表结构） |
| 10 | 客户端无 CI/门禁脚本 | 回归靠人 | 见批次 1 并行项 |
| 11 | 界面缩放用 CSS `zoom` 作用在根元素 | 浏览器（Chromium）下 200% 无溢出已实测；Wails 的 WebKitGTK / WebView2 / WKWebView 需在桌面端各实测一次 | 桌面端验证后回填结论；若有偏差改为按 webview 分支实现 |
| 12 | 树操作对齐 web 时**多做**了「请求行重命名」 | 与 web（叶子行仅删除）略有差异，桌面端更顺手 | 若要求严格一致可去掉该按钮（`RenameRequest` 接口保留） |
| 13 | 分组重命名只改 `folder.yml` 的 `info.name` | 目录名不变（路径稳定），但目录名与显示名会不一致 | 已确认符合 Bruno/uid 稳定优先；如需同步目录名需再做一次迁移 |
| 14 | 无 D-Bus 会话总线时 GTK 文件对话框输出 `dconf-WARNING ... dbus-launch (No such file or directory)` | 刷屏警告，不影响功能（WSLg/最小容器常见） | 已兜底：无会话总线且用户未指定 `GSETTINGS_BACKEND` 时自动用 `memory`（`internal/platform/gsettings.go`）；代价是文件对话框不记忆上次目录 |
| 15 | `md-editor-v3` 体积较大（自带 highlight.js 多语言分块，构建产物 ~113 个 chunk） | 构建变慢（本地 ~12s，超过 10s 的默认观察窗口）、安装包变大 | 与服务端 Web 保持一致优先；后续可考虑按需裁剪语言/`manualChunks` 拆分 |
| 16 | 文档编辑器渲染沿用 `md-editor-v3` 默认转义（原始 HTML 不当富文本执行） | 与 Web 行为一致、无 XSS；代价是不能在文档里内嵌原始 HTML | 如确需内嵌，需显式开启并接入 DOMPurify（`sanitize` prop），勿裸开 |
| 17 | 图标库与编辑器为新增前端依赖（`@vicons/ionicons5`、`md-editor-v3`），已移除 `markdown-it` | 换机需 `npm install` | 提交 `package-lock.json` |
| 18 | Wails 用 **WebKitGTK 4.0**（`libwebkit2gtk-4.0.so.37`），Web 端是 Chromium | 字体度量、原生控件、滚动条、`zoom`/`color-mix`/`:has` 等支持度不同 → 无法像素级一致 | 已对齐主题与排版（A13）；目标定为「尽量一致」，个别组件必要时做引擎分支 |
| 19 | 本机中文字体仅 1 个（Droid Sans Fallback、无粗体字面） | 中文曾出现合成粗体偏粗、字形跳变/方块 | 已由 A14 解决：随包内置 Noto Sans SC 可变字体 + 禁合成粗体；新增代价见下条 |
| 20 | 内置字体使 `frontend/dist` 从 2.8 MB 涨到 7.5 MB（98 个 woff2 子集共 4.6 MB），Wails 内嵌后二进制同步增大 | 安装包/二进制体积 | 按需加载只影响首包体积不影响运行；如需压包见 A15（子集化到 1.5–2 MB） |
