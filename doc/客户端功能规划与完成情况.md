## 4. 后续规划（客户端视角，按批次交付）

> 排序原则：先做**不依赖服务端**且能独立验收的项；同步类整体推迟到服务端 P0 落地之后。

### 批次 1｜编辑体验补完（P3 验收缺口，无外部依赖）
- **G6 会话持久化**：tab 现场（uid 列表、activeKey、草稿引用）落配置目录，启动恢复；关闭时 flush。
- **G11 快捷键落地**：`Ctrl+Enter` 发送、`Ctrl+N` 新建、`Ctrl+E` 环境、`Ctrl+W` 关闭 tab、`Ctrl+S` 立即保存。
- **G5 取消发送**：`runner.Send` 接受 `context.Context`，UI 提供取消按钮（App 层按 tab 存 cancel）。
- **G9 撤销/重做**：编辑器级（单请求范围内）。
- **H3 Cookie 面板**：列表 + 单条删除（复用 `ListCookies`）。
- **验收**：重启应用后 tab 与草稿恢复；快捷键与空态提示一致；取消发送后状态回到空闲。

### 批次 2｜执行器与文件层补完（P5 主干）
- **E15/E16/E17 断言 + 脚本钩子 + 前置变量**：引入 goja；`bru.setVar/getVar` 最小 API；断言结果进响应面板。
- **E21 二进制保存到文件**：Wails 保存对话框 + `SaveResponseBody`。
- **E18 文件上传**：multipart file part（含路径变量）。
- **B11 重命名/移动**：请求与分组（改路径需保持 `meta.uid` 不变）。
- **C1 本地索引（SQLite）**：`node(uid,type,path,title,method,url,mtime,hash)`，树与搜索改走索引，可重建。
- **验收**：断言失败有明确提示；脚本能设变量并在后续请求/预览中生效；索引删除后自动重建且行为一致。

### 批次 3｜互操作与导出（P1/P5）
- **C2 索引驱动的一致性校验** + **H8 导入向导**（Bruno 目录批量修复/报告）。
- **H9 Postman / OpenAPI 导入**（建议先抽共享 `pkg/*`，见设计文档 F3）。
- **H10 导出 Markdown / 单文件 HTML**（与服务端 Web 行为对齐）。
- **H6 代码生成 cURL**。
- **验收**：Bruno 样例集合导入导出逐字段一致；Postman v2.1 / OpenAPI 3.0 样例可导入并发送成功。

### 批次 4｜协作与同步（待服务端 P0 完成）
- I1–I6 全部；启动前先与「服务端 P0/P0.5 验收」对齐契约（`doc/api_docs/sync/*`）。
- **验收**：两台设备交替改同一集合，能拉到对方改动、推送、冲突生成副本并可一键取舍；离线积压联网后自动补齐。

### 工程门禁（可与批次 1 并行）
- 新增 `scripts/check.sh`（gofmt → go build → go vet → go test → vue-tsc → eslint → vite build）与 CI，使 A6 转 ✅。

| 端到端 | `go build -o .tmp/devserver-test ./cmd/devserver` → 以**独立端口/独立 `XDG_CONFIG_HOME`** 启动 → 浏览器驱动 | 打开集合 → 打开请求 → 严格模式发自签 HTTPS 失败 → 设置开启忽略 SSL → 200 → 认证头真实注入 → 历史记录 |

**回归要点（改动执行器/文件层时必跑）**：
1. 证书策略：严格必须失败、忽略必须成功（自签端点 `-tls-echo`）。
2. 重定向：跟随/不跟随/超上限三种行为。
3. round-trip：Bruno 样例句含 `auth: inherit`、`vars/script/assert` 时，读入保存后**未知字段不丢**。
4. 自写回环：自动保存不应把编辑器内容覆盖掉（批次 2 引入 fsnotify 后强制回归）。
