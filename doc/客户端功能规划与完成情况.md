> **维护方式**：完成一项就改「状态」列并补「落点」；新增功能点追加编号，不复用旧号。
> **相关文档**：gRPC 见《客户端gRPC测试功能设计.md》；MCP 见《MCP服务设计.md》《MCP服务使用手册.md》；问题与修复过程见《客户端问题记录.md》。

## 5. 验证与回归方式

门禁（提交前必跑，秒级）：`bash scripts/check.sh` = gofmt → go build → go vet → go test → vue-tsc → i18n key 校验（CI 同源）。

端到端（耗时，按需）：`bash scripts/check.sh --smoke`（+ 前端构建 + `@smoke` e2e，约 1 分钟）、
`--full`（+ 全量 e2e，约 3 分钟）、`--e2e-ui`（Playwright UI 调试）。用例在真实构建产物上驱动真实 App 门面方法，
同时断言 UI / 集合文件 / 真实响应；夹具服务 `cmd/testfixtures`（受控故障矩阵）与用例说明见 `frontend/e2e/README.md`。
当前 **49 条回归 + 1 条 @demo**。

**改动执行器/文件层/编辑流程时的人工回归要点**：

1. 证书策略：严格必须失败、忽略必须成功（自签端点 `-tls-echo`）。
2. 重定向：跟随 / 不跟随 / 超上限三种行为；跨域重定向时凭据类自定义头必须被丢弃并在响应区提示。
3. round-trip：Bruno 样例句（含 `auth: inherit`、`vars/script/assert`）读入保存后未知字段不丢；**manifest 未知键同样不丢**。
4. 自写回环：自动保存不得把编辑器内容覆盖掉。
5. 树操作：空分组可见、重命名后目录名/uid 不变、非空分组拒删、删除进 `.trash`（`folder_test.go`）。
6. 保存模型：手动模式下编辑不写盘、`Ctrl+S` 落盘；外部改动 → 干净页签回填、脏页签冲突条两个出口。
7. 响应区三态互斥：未发送（状态栏占位 + 空态）、已发送（状态码 + 页签 + 内容）、出错（只显示错误条）。
8. 超限响应：>10 MB 时显示「已截断（实际 N）」且不丢告警。
9. 环境变量：改完保存后地址栏悬停立即显示新值；敏感值只显示掩码。
10. 界面：语言/主题切换即时生效、缩放 200% 无溢出、响应区右侧/底部切换、弹窗打开不改变整体尺寸。
11. 字体：`document.fonts.check('14px "Noto Sans SC Variable"', '用户管理')` 为 `true`，`font-synthesis: none`。
12. gRPC：定义导入 → 服务/方法选择 → 样例消息 → 发送/校验（见 gRPC 设计文档 §10）。
13. MCP：内嵌与独立服务都能 `initialize` / `tools/list` / `tools/call`；只读模式下写工具返回 `unknown tool`。
14. 真窗口项（发版前人工）：无边框拖动、窗口透明圆角、窗口控制、字体渲染观感、缩放手感。
