## 2. 架构与代码地图

```
main.go ──▶ internal/app（Wails 门面，115 导出方法；事件总线 / 多根集合 / 窗口自适应）
              ├─ collection/   集合文件层（YAML round-trip / uid / .trash / secrets / examples / docs / protos / assets）
              ├─ runner/       请求执行（HTTP + gRPC：变量渲染 → 发送 → 脚本/断言 → 结果）
              ├─ proto/        .proto 纯 Go 编译（protocompile）+ 缓存 + 字段/样例
              ├─ varx/ script/ cookiejar/ history/ index/ watch/ mocksrv/
              ├─ syncengine/   同步客户端（pull/push/冲突/游标/绑定）
              └─ mcp/ mcpauth/ mcpaudit/   MCP 服务 + 授权 + 审计
cmd/        devserver（无桌面驱动 + 反射桥）/ mcpserver（独立 MCP）/ clientctl（内核 CLI）
            grpcfixture + testfixtures（联调与 e2e 夹具服务）
frontend/   App.vue（外壳/布局/快捷键）+ components/* + stores/{tabs,collection,settings} + lib/*
            lib/ipc.ts 是前端访问内核的唯一入口（Wails 绑定探测 → devserver 反射桥回退）
```

分层单向：`handler(无) → app 门面 → 各 internal 包`；前端不直接碰 Wails/devserver。

**改动执行器/文件层/编辑流程时的人工回归要点**：

1. 证书策略：严格必须失败、忽略必须成功（自签端点 `-tls-echo`）。
2. 重定向：跟随 / 不跟随 / 超上限三种行为；跨域重定向丢弃凭据类自定义头并提示。
3. round-trip：Bruno 样例句读入保存后未知字段不丢；manifest 未知键同样不丢。
4. 自写回环：自动保存不得覆盖编辑器内容。
5. 树操作：空分组可见、重命名后目录名/uid 不变、非空分组拒删、删除进 `.trash`。
6. 保存模型：手动模式下编辑不写盘、`Ctrl+S` 落盘；外部改动 → 干净页签回填、脏页签冲突条。
7. 响应区三态互斥：未发送 / 已发送 / 出错；>10 MB 显示「已截断（实际 N）」。
8. 环境变量：保存后地址栏悬停立即显示新值；敏感值只显示掩码。
9. 界面：语言/主题切换即时生效、缩放 200% 无溢出、响应区右侧/底部切换、弹窗不改变整体尺寸。
10. gRPC：定义导入 → 服务/方法选择 → 样例消息 → 发送/校验。
11. MCP：内嵌与独立服务都能 `initialize`/`tools/list`/`tools/call`；只读模式下写工具返回 `unknown tool`。
12. 真窗口项（发版前人工）：无边框拖动、透明圆角、窗口控制、字体渲染、缩放手感。
