2026.10.28 已完成 =================

40. 修复集合树徽标文字右对齐：请求的 GET/POST、文档的 MD 原先在 34px 徽标列内贴右缘（`justify-content: flex-end`），字头按词长错开（GET 的 G 与 POST 的 P 不在同一列），且标题只剩 1px、MD 几乎贴住标题；改为左对齐后 G/P/M 同列，MD 与标题恢复到约 16px 间距。纯显示层调整，不涉及数据与文件。

41. 修复「MD 文档被 MCP 更新后，界面既不刷新也不提示重载」：文档页签打开时没有记录磁盘 hash 基线（请求页签有），外部改动在「外部改动回填」里被 `!baseHash` 直接跳过——干净页签不刷新、脏页签也不弹冲突条；现在打开文档页签即记录基线：干净页签自动回填新正文，有未保存编辑时弹冲突条。顺带补齐冲突条两个出口对文档的支持（「重新加载」走 ReadDoc；「另存为副本」新建同名 .md 并切过去），并让首次保存也带 expectHash，避免静默覆盖 MCP 写入。

42. 冲突 / 外部删除新增「仍然保存」出口：文档被外部（MCP 等）删除后，页签保留内容并弹出提示条（「文档已被外部删除」），可点「仍然保存」（二次确认）用当前内容重建文件，也可直接 Ctrl+S 重建；文件只是被外部改动的写冲突也多了这个出口，可用本地编辑覆盖磁盘版本（不再只有「重新加载 / 另存为副本」）。文档被删场景下提示条隐藏「重新加载」；重建/覆盖成功后树自动补回该行。

43. 修复「重启后打开 MCP 设置，明明没改却提示『配置已修改』」：Go 侧把空的来源白名单归一成 `null`，前端 store 直接透传、而设置对话框把 `allowOrigins` 归一成 `[]`，脏检查用 JSON 快照比较 `null ≠ []`，于是一打开就判为已修改。现在 store 加载时把 `allowOrigins` / `allow` 统一补成 `[]`，快照与 MCP 脏检查也按 `[]` 比较；新增 e2e 回归（首次打开 / 原样保存后再打开 / 刷新后重开，都不显示未保存提示）。

44. 修复集合树行右键菜单不消失：右键菜单是受控 `NDropdown`（`trigger="manual"`），手动模式下选中条目不会自动关闭，点击别处也不会关，菜单会一直浮在原位置。现在选中即关闭，并补齐「点击外部 / Esc / 滚动 / 窗口失焦 / 光标进过菜单后移开（400ms 延迟）」出口；新增 e2e `[T22]`（选中 / 点外部 / Esc / 滚动 / 移开），改动前同一用例在「选中后」即复现残留。

45. 修复 Linux 下窗口缩小后无法拖动边框调整大小：桌面态外壳为了画外阴影让出 `--app-frame-gap`（32px），用户拖的可见边框离窗口外沿 32px；而 Wails 运行时的边缘检测只认窗口外沿 6px（`outerWidth - clientX`），最大化时留白归零所以此前看起来「能用」。现新增 `WindowResizeHandles.vue`：在可见边框内侧放 6px 热区，按下直接发送运行时同款 `resize:<edge>` 消息（Linux 后端交给 GTK `begin_resize_drag`），不再依赖 `outerWidth`；仅在桌面 Linux 且非最大化时显示。e2e `[T23]` 覆盖可见/发消息/最大化隐藏。
