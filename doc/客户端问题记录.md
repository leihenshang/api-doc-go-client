## 2026.10.2

- [x] 窗口：双击标题栏最大化 / 还原（用户询问「能不能双击顶部栏自动全屏」）
  - 结论：Wails v2 的无边框窗口**不带**这个行为 —— 拖动区由注入的 runtime JS 驱动（`--wails-draggable` 元素上 `mousedown` 且 `detail === 1` 时才 `WailsInvoke("drag")` → Go 侧 `WM_NCLBUTTONDOWN + HTCAPTION`），系统层面的「双击非客户区标题栏」永远不会触发（webview 属客户区，`WM_NCHITTEST` 不会给 `HTCAPTION`），Wails 自身也没有 `dblclick` 处理。
  - 改法：`TitleBar.vue` 在自绘标题栏上接 `@dblclick` → 调已有的 `WindowToggleMaximise()`（落在窗口控制按钮/主题按钮上的双击不参与）。**静止双击能可靠收到 `dblclick`**：Wails 运行时默认 `flags.deferDragToMouseMove = true`（v2.16 生产包同样是 `!0`），拖动要等 `mousemove` 才真正进入系统移动循环，所以单击/双击不会被移动循环吃掉。
  - 配套：最大化状态改为统一同步（`syncMaximised()` + 窗口 `resize` 防抖兜底），并把状态写到根节点 `data-window`；`base.css` 里 `:root[data-window='max']` 把 `--app-radius-window` 归零 —— 否则最大化后四角会透出桌面（窗口是透明的）。按钮切换后延迟 80ms 回读，图标不再停在旧状态。
  - 边界：这是「最大化」（占满工作区、不盖任务栏），与系统标题栏一致；若要 F11 那种真全屏（盖住任务栏）需另加 `WindowFullscreen`。贴边分屏（Snap）时窗口只贴三边，`IsZoomed()` 为 false，圆角不归零（暂按原样）。
  - 验证：浏览器 + 假 Wails 运行时（`window.go.app.App` 只实现窗口方法，其余 IPC 仍回落 devserver 桥）：单击标题栏不最大化、双击最大化（`data-window=max`、`--app-radius-window: 0px`）、再双击还原、双击主题按钮与窗口按钮不误触发；`bash scripts/check.sh` 全过。真窗口可按下方命令核对。

## 2026.9.29

- [x] 响应面板错误态退化成纯文本

- [ ] 待确认：`multipart` 请求体与显式 `Content-Type` 头的交互
  - 现状：`internal/runner/runner.go` 仅在请求头**为空**时才注入由 body 推导的 `Content-Type`（`if contentType != "" && req.Header.Get("Content-Type") == ""`）。因此请求里若已存在 `Content-Type: application/json`，multipart body 就带不上 boundary，服务端解析失败。
  - 取舍：显式头优先是通用语义，但对 `type: multipart` 而言显式头必然是错的（boundary 是发送时生成的）。可选改进：body 为 multipart 时覆盖/告警。
- [x] 环境变量「保存」看起来没生效（实际是解析没刷新 + 没有任何反馈）
  - 现象：改完变量点保存，集合文件已经写对了（`environments/dev.yml` 内容正确），但界面毫无反应：没有 toast、地址栏的「替换后」仍是旧值，用户只能判断成「保存按钮坏了」。
  - 根因：`EnvManager.save()` 从未 `emit('saved')`，而 `App.vue` 的 `envSaved()`（唯一会调 `tabs.refreshResolve()` 的地方）挂在 `@saved` 上 → 地址栏变量解析停留在上一次结果；同时保存/新建/删除都没有 try/catch 与提示，后端报错也静默。
  - 改法：保存 / 新建 / 删除环境成功后统一 `emit('saved')` 触发重算，并弹 toast `已保存环境「<name>」`；失败把错误原样提示。已在浏览器实测：改值保存后悬停该变量即为新值。
- [x] 地址栏常驻「替换后 {{host}}xxxx」预览行（未定义变量时把原文当成结果展示）
  - 改法：删掉该行，改为 `VarInput` 内**悬停变量才出提示**：已定义显示 `名字 = 值`；敏感变量按当前环境 `secret` 标记只给 `••••••` + 「敏感变量：值已隐藏」；未定义提示去「环境设置…」补（片段警告底色 + 输入框警告描边，定义后自动消失）；空值提示「（空值）」；内置变量说明「发送时生成」。取值由后端新增的 `ResolveResult.Values` / `varx.CollectValues` 给出（与 `missing` 同源），未拿到解析结果时不提示，避免误报「未定义」。
