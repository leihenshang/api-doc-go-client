## 2026.10.5（代码审核：安全 / 边界 / 逻辑修复）

一轮全量代码审核（含二轮逻辑专项）后按严重度修复，并补齐回归测试（`bash scripts/check.sh` 全绿）：

**高危**

- [x] **文档附件下载把 PAT 明文发给任意第三方地址**：`App.SyncDocAssets` 对文档里的 `http(s)` 图片原样带上 `Authorization: Bearer <PAT>` 下载，且无超时、无大小上限 → 克隆/同步来的不可信文档即可窃取令牌并 SSRF。改法：`assetURL()` 只接受「服务端同源绝对地址」或「相对路径（按服务端补全）」，其余跳过；专用 client（60s 超时）+ 32 MB 读取上限。回归：`internal/app/asset_test.go`。
- [x] **devserver 反射桥无门禁**：`/api/App/<Method>` 可被任意网页用 `fetch(..., mode:'no-cors')`（text/plain 简单请求，无预检）触发 `OpenCollection`/`SaveDoc`/`RunSync` 等；`-addr` 非回环时局域网任意主机可读写集合。改法：`guardAPI` 三重门禁（Host 必须本机 → 防 DNS rebinding；带 Origin 必须是本机来源；只接受 POST + `application/json`；`-token` 非空时校验 `X-Dev-Token`），且**绑非回环必须给 `-token`**（不给拒绝启动）。前端 `ipc.ts` 从 `localStorage['dev.token']` 带上该头。
- [x] **`Registry.scan()` 对每个项目调 `collection.Open`**：只读的「列项目」会为每个项目建索引、写清单、起 fsnotify 并**永不释放**（每次 `refresh=true` 再泄漏一轮）。改法：新增只读的 `collection.ReadMeta`（不写盘/不建索引/不监听），scan 改用它；`CreateProject` 的临时实例显式 `StopWatch` + `CloseIndex`。

**中危**

- [x] **内嵌 MCP 令牌未落盘 → 静默轮换**：`applyMCP` 在写回 `a.settings` **之后**才生成令牌，只存在于状态里；切主题（`setTheme` → `saveSettings` 写空令牌）或重启即换新，已连上的 AI 客户端 401。改法：生成后落盘（失败则把原因挂到状态）。
- [x] **索引路径取自未校验的 manifest UID**：`meta.uid: ../../x` 会让 sqlite 建到配置目录之外（`MkdirAll` + 建表 = 越界写盘）。改法：`safeIndexName()` 白名单校验，非法则退化为 UID 哈希。
- [x] **`Collection.SaveDoc` 未校验 `Path`**：与 `SaveRequest`/`protoPath` 不同，它直接把前端/桥传入的路径拼进 `filepath.Join` → 任意路径写 `.md`。改法：`docPath()` 要求落在集合 `docs/` 内且为 `.md`。
- [x] **goja 脚本/断言无超时**：`while(true){}` 让 `SendRequest` 永久挂死（脚本来自请求文件 = 不可信）。改法：`runWithTimeout`（5s，`vm.Interrupt`）并回报「脚本执行超时」。
- [x] **响应体 >10 MB 静默截断**：`Size` 报截断后长度、无任何提示，保存响应体会写出不完整文件。改法：多读 1 字节判定截断，`Result.Truncated/FullSize/Warnings` + 响应区提示「已截断（实际 N）」。
- [x] **multipart 文件字段无边界**：集合里的任意路径都会被读出上传，大文件直接进内存。改法：只接受普通文件 + 100 MB 上限（`readUploadFile`）。同时修掉「显式 `Content-Type` 覆盖 multipart 派生值导致丢 boundary」的老问题（现在 multipart 一律用派生值）。
- [x] **Cookie 罐不校验 `Domain`/`Secure`**：任意站点可用 `Domain=victim.com` 往别人域里塞 Cookie（甚至 `Domain=com` 的超级 Cookie），`Secure` Cookie 也会走 http。改法：Domain 必须是请求主机本身或其父域（拒单标签 TLD）、未下发 Domain 记为 host-only 不再匹配子域、`Secure` 只在 https 下发。已知限制：未实现 Public Suffix List。
- [x] **同步客户端不强制 https 且不校验业务码**：PAT 可能明文过网；`Meta()` 把错误码当好结果。改法：`ValidateServerURL`（非回环禁明文 http），`Meta` 判 `code != 200`，响应读取限 32 MB。
- [x] **同步分页无上限**：服务端恒返回 `has_more`（或忽略 `offset`）时无限循环。改法：页数上限 + 游标未推进即停。
- [x] **配置项只有下限没有上限**：超大 `timeoutSec` 在换算 `time.Duration` 时溢出成负值、`historyLimit` 让历史文件无界增长。改法：`Normalize` 与 `runner` 两侧都夹上下限。

**低危 / 边界**

- [x] 重定向上限 off-by-one（`>` 而非 `>=`）；每次发送后 `CloseIdleConnections()`。
- [x] 请求头/API Key 名值校验（拒 CR/LF/NUL，防头注入）；**跨域重定向丢弃凭据类自定义头**并回告警（同源不丢）。
- [x] 草稿发送取消键错位（前端传 `draft-…`，Go 按请求 uid 登记）→ 改为传真实 uid；Go 侧草稿单独登记，互不取消。
- [x] `App.SearchIndex` 把 `limit<=0` 归一成 200，导致「取全量」的内部调用（冲突检测 / MCP hash）在 >200 请求的集合上静默丢结果 → 改为 0 = 不限。
- [x] `GenerateCode` 丢弃 `apikey + in=query` 认证 → 现在会拼进 URL（与真实发送一致）。
- [x] `curl` 的 URL fragment 残留在最后一个参数值里 → 先整体丢 fragment。
- [x] 导出 HTML 的 `inlineMD` 会产出交叉/未闭合标签 → 改为按 code span 优先的单遍扫描；表格单元格转义 `|`、分隔行严格判定。
- [x] 带点号的目录名（`v1.0/`）新建后不会补挂 watch（扩展名过滤先于目录判断）→ 调整顺序并跳过 `.trash`/隐藏目录。
- [x] 示例保存的「选名 → 算序号 → 写文件」非原子（并发同名互相覆盖）+ 去重上限 off-by-one → 加锁 + 修正循环。
- [x] MCP `set_env_var` 对**新建**敏感变量传掩码会存成假密钥 → 直接报错（已存在的仍视为「不改」）。
- [x] Mock 回放示例里 `status: 0` 时 `WriteHeader(0)` panic → 非 100–599 回退 200。
- [x] `history.jsonl` 权限 0644（含请求快照与凭据）→ 0600；索引 sqlite 同样收权。
- [x] `MoveFolder`/`manifest`/监听退出：切换集合时 `watchLoop` 因 `out` 不关闭而永久阻塞 → `Watcher.Done()` + `select` 退出；`writeManifest` 改为读改写 YAML 节点（保留未知键、顺序、注释）。
- [x] `startMock` 换集合后仍服务旧集合 → `OpenCollection` 时停掉并重建。
- [x] gRPC proto 入口/import 允许绝对路径与 `..`（不可信集合可诱导读本地文件）→ 入口必须在集合内，`protocompile` 的 resolver 上包一层沙箱拒绝 `..`/绝对路径。
- [x] `IsBrunoDir` 递归无深度上限；内嵌 MCP 地址兜底改为回环（`127.0.0.1`）。

## 2026.10.5（环境变量 MCP 工具 · 代码评审修复）

评审用临时探测测试在 Windows 上复现 5 个缺陷（前 3 个是数据丢失级）：

- [x] `create_env("DEV")` **静默覆盖**已存在的 `dev` 并销毁密钥 🔴：环境名即文件名，判重用 `e.Name == name`（大小写敏感），而 NTFS 不区分。改法：`indexOfEnv` 改 `EqualFold`。
- [x] `rename_env("dev"→"DEV")` 报成功但环境消失 🔴：改名是「写新名 + 删旧名」，同一文件等于先写回再自删。改法：服务层与 `Collection.RenameEnv` 都用 `EqualFold(旧路径,新路径)` 拒绝。
- [x] `set_env_var` 对**新增**变量忽略 `enabled: false` 🔴：赋值写在「找到同名变量」的循环体内。改法：初值在循环外定。
- [x] 环境写入无并发保护，`list`→`set` 期间他人改动被抹掉 🟡：改法：`EnvFileHash` + `SaveEnvChecked`（git 风格前缀比对），三个写工具收 `ifMatch`。附带发现：改名若在原层拼「写新 + 删旧」，`SaveEnvChecked` 拿到的是新名 → 哈希为空 → 校验被静默跳过，故改名下沉到 `Collection.RenameEnv`。
- [x] `isMaskish` 把 `.`/`?` 当掩码 → 真实密码被静默忽略 🟡：字符集收窄为 `• ● · *`。

## 2026.10.3

- [x] 保存模型四个缺口（全部修复）：① 无冲突检测（整文件覆盖）→ `Request.ExpectHash` + 写盘前比对，不一致拒写（`[conflict]`）+ 前端冲突条两个出口（重新加载 / 另存为副本）；② 打开中的页签不随外部改动刷新 → 干净页签回填、脏页签标冲突；③ 关窗有 ~800ms 丢失窗口 → 失焦即 `flushAll`、切集合先 `reset()` 落盘，浏览器态补 devserver SSE 事件桥；④ 反馈缺失 → 状态栏「保存中/已保存」、草稿写失败提示、mirror 拒写。**行为调整：自动保存改为设置项且默认关闭**（手动保存模式）。
- [x] 集合树真机拖不动：① WebView2 下 HTML5 拖拽不可靠；② 守卫「target 落在任意 button 内就跳过」把整行（名字本身是 button）排除。改法：指针事件自实现拖拽（4px 阈值 + `elementFromPoint` + Esc 取消）；顺带修「拖动提示条把行往下推导致放错行」（改绝对定位浮层 + `pointer-events: none`）。验证改用真实鼠标事件。
- [x] 拖动改上级目录报「分组不存在」：① `resolveFolder` 只认带 `folder.yml` 的目录；② 无 `folder.yml` 的目录 uid 是空串 → 加 `resolveFolderForMove` + `dir:<路径>` 兜底 uid；`App.SaveRequest` 以磁盘索引里的真实路径为准（防「移动后在旧目录又写一份」）。
- [x] MCP `search_requests` 深读路径丢失 `project`/`hash`：`matchFromNodes` 未填。改法：一并带上。
- [x] MCP `ifMatch` 用界面展示的短 hash 必然被拒（全等比较 vs 12 位前缀）→ 改为 git 风格前缀匹配（≥8 位，更短直接判冲突）。已知残留：文件监听重建索引有几百毫秒延迟，紧接着取 hash 偶尔偏旧 → 重读一次即可（已写进手册排查表）。
