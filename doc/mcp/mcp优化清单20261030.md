### T14 `create_project` 错误码与 root 语义 ✅

- `root` 必须是**工作目录**；若指向项目目录本身 → `[INVALID]` 并提示改传父级（此前会嵌套创建，随后「找不到项目」）
- **不传 root 时**：默认选第一个可写目录；若该目录本身是项目，同样 `[INVALID]` 并提示改为父目录（评审环境的实际根因）
- 错误码映射：白名单外 `[AUTH]`、只读 `[READONLY]`、重名 `[CONFLICT]`、非法名 `[INVALID]`、其它 `[IO]`（不再一律 `[INTERNAL]`）

### T15 `list_docs` 带 hash 的性能 ✅

- 新增 `Collection.DocHashes()`：一次扫描 + 逐文件读，替代「逐篇 `DocFileHash`（每篇重扫）」
- 实测 30 篇：`includeHash=true` 168ms → **24ms**（`includeHash=false` 2ms）；默认仍按决策返回 hash
