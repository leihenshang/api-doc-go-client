# CodeBuddy 复刻提示词

> 使用方法：在 CodeBuddy 中新建会话，粘贴下方整段提示词，然后把两张 PNG 一起拖入对话即可。

---

请根据我提供的两张设计图，用 Vue 3 + TypeScript + Naive UI 复刻一个 API Client 的「响应面板」组件。

**图片说明**
- 图1「01-响应面板-主视图.png」是完整面板的默认态
- 图2「02-保存菜单-展开态.png」是点击「保存 ▾」按钮后的下拉菜单浮层

**整体要求**
- 严格按图还原布局、间距、圆角、颜色，不要自行增删元素
- 全中文界面文案（GET/POST/JSON 等术语保留英文），代码/URL/JSON 用 JetBrains Mono
- 图标统一用 lucide-vue-next 线条风格（stroke-width 2）

**色彩令牌**
- 主绿 #18A058（激活态/主按钮/成功徽章）；深绿 #0E7A3E（浅绿底上的文字）；浅绿底 #E8F5EE
- 文字：主 #18191C、次 #4E5969、弱 #8A8F98；边框 #E3E3E3；浅灰底 #F5F5F5
- JSON 高亮：key 绿 #18A058 / 字符串橙 #D46B08 / 数组索引蓝 #2080F0

**结构（自上而下）**
1. 状态栏（h44，底边框）：左 =「响应」标题 + 「200 OK」绿底白字圆角徽章 + 「12 ms · 145 KB」等宽灰字；右 =「本次响应 ▾」描边下拉（用于切换历史响应）
2. 响应标签栏（h40，底边框）：左 = Tab 组间距 20：「响应体」（激活：绿字 + 2px 绿下划线）、「响应头」（带灰色计数徽标 2）、「响应字段」（计数徽标 6）；右 = 请求 URL 等宽 11px 灰色弱化
3. 操作工具条（h44，底边框，两端对齐）：
   - 左侧按「视图→显示」分组：① 美化/原始 分段控件（外框 #F5F5F5 圆角 6，激活项白底描边圆角 4 绿字）；② 「展开全部」图标按钮；③ 「换行」开关胶囊（开启态 #E8F5EE 底深绿字）
   - 右侧按「解析→输出」分组：④ 「更新响应字段」白底描边按钮带刷新图标；⑤ 竖分隔线；⑥ 「复制响应体」幽灵按钮带复制图标；⑦ 「保存 ▾」唯一主按钮：#18A058 实底白字圆角 6 带下拉箭头
4. JSON 树内容区：行高 24、每级缩进 20px、hover 圆角 4；演示数据为地区树形数组（value/label/children，如 AF/非洲、AO/安哥拉、BGU/本吉拉省），含展开箭头（下=展开、右=折叠）

**保存下拉菜单（图2）**
- 240px 宽浮层，白底圆角 8、边框 #E3E3E3、投影 0 8px 20px rgba(0,0,0,.18)
- 三个菜单项（高 34、左内边距 12）：保存响应体为文件（.json）/ 保存全部字段为变量 / 保存选中值为变量
- 底部分隔线后：「作用域」标签 + 集合/环境/全局 三个 chips（#F5F5F5 圆角 4），可单选

**交互逻辑**
1. 三个 Tab 内容互斥显示，切换 Tab 只改可见性
2. 美化/原始互斥（分段控件）；换行是开关态
3. 「更新响应字段」点击后解析 JSON 生成字段表格（字段路径/值/类型/含义/变量书签 5 列），多次点击只追加新字段、永不删除已有字段
4. 「保存 ▾」点击弹出图 2 菜单；菜单项按作用域 chip 保存
5. 组件拆分为 ResponsePanel / ResponseToolbar / SaveDropdown / JsonTree 等子组件，props 明确、便于嵌入现有请求编辑器

完成后请提供可直接运行的 SFC 代码与目录结构说明。
