# 响应面板重设计 · 设计规格

> 画布：https://ardot.tencent.com/file/731403613380243
> 画板：主视图 960×640（01-响应面板-主视图.png）、保存菜单展开态（02-保存菜单-展开态.png）

## 1. 技术栈

- Vue 3 + TypeScript + Naive UI
- 图标：lucide-vue-next（线条风格，stroke-width 2）
- 代码字体：JetBrains Mono；界面字体：Noto Sans SC / system-ui

## 3. 结构（自上而下）

```
响应面板 (vertical, 960×640)
├─ 状态栏 h44，底边框
│   左：`响应` 标题(13 SemiBold) + `200 OK` 绿徽章 + `12 ms · 145 KB`(mono 12 灰)
│   右：`本次响应 ▾` 下拉（描边胶囊，切换历史响应）
├─ 响应标签栏 h40，底边框
│   左：Tab 组（gap 20）——响应体(激活：绿字+2px绿色下划线) / 响应头(计数徽标²) / 响应字段(计数徽标⁶)
│   右：请求 URL，mono 11 灰色弱化
├─ 操作工具条 h44，底边框，左右 SPACE_BETWEEN
│   左侧分组（gap 8）：
│   ① 视图模式分段控件：外框 #F5F5F5 圆角6 padding2；「美化」激活=白底描边圆角4绿字；「原始」未激活灰字
│   ② 「展开全部」图标+文字（灰底 #F5F5F5 圆角6）
│   ③ 「换行」开关态胶囊（激活=#E8F5EE 底 #0E7A3E 字）
│   右侧分组（gap 8）：
│   ④ 「更新响应字段」刷新图标+文字，白底描边圆角6
│   ⑤ 竖分隔线 1×16
│   ⑥ 「复制响应体」复制图标+文字，幽灵按钮（无底无框）
│   ⑦ 「保存 ▾」唯一主按钮：#18A058 实底白字圆角6，带下拉箭头
└─ JSON 内容区（vertical, padding 16/12）
    行高 24，每级缩进 20px，hover 行圆角4
    key=绿 mono / 字符串=橙 mono / 数组索引=蓝 mono / 折叠箭头=灰色 10×10
    演示数据：[…] → 0:{value:"AF", label:"非洲", children:[…]} → 0:{value:"AO", label:"安哥拉", children:[折叠]} / 1:{value:"BGU", label:"本吉拉省", children:[折叠]} / 2:{…}[折叠]
```

## 4. 保存下拉菜单（展开态）

- 浮层：240×164，白底圆角8，边框 #E3E3E3，阴影 y8 blur20 rgba(0,0,0,.18)
- 菜单项 h34，左对齐 padding 12：
  1. 保存响应体为文件（.json）
  2. 保存全部字段为变量
  3. 保存选中值为变量
- 分隔线后底部：`作用域` 标签(11 灰) + chips 集合/环境/全局（#F5F5F5 圆角4）

## 5. 交互要点（需实现）

1. Tab 切换独占显示：响应体 / 响应头 / 响应字段三块内容互斥，激活 Tab 绿字+下划线
2. 美化/原始为互斥分段控件；换行为可开关状态
3. 「更新响应字段」点击后才解析 JSON 生成字段表；多次更新只追加新字段不删除
4. 保存▾ 下拉三种保存方式；作用域 chips 单选
5. 状态栏「本次响应 ▾」下拉切换历史响应
